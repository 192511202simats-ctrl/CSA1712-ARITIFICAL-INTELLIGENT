# EX-31. WEB BLOG USING WORDPRESS

**AIM**

To create a web blog using WordPress and demonstrate Anchor Tag and Title Tag.

**OBJECTIVE**

1. To create a basic web blog.
2. To demonstrate the HTML title tag.
3. To demonstrate the HTML anchor tag.
4. To publish a simple blog page.

**ALGORITHM**

1. Start.
2. Open WordPress.
3. Select a suitable theme.
4. Create a new page or post.
5. Add title and content.
6. Add an anchor link.
7. Publish the page.
8. Open the blog in a browser.
9. Stop.

**FLOWCHART**

```

  ↓

```

**PYTHON CODE**

```html
<!DOCTYPE html>
<html>
<head>
    <title>My Web Blog</title>
</head>

<body>

    <h1>My Technology Blog</h1>

    <p>Welcome to my web blog.</p>

    <a href="https://wordpress.org/">
        Visit WordPress
    </a>

</body>
</html>
```

**SAMPLE OUTPUT**

```
My Technology Blog

Welcome to my web blog.

Visit WordPress
```

**RESULT**

A basic web blog containing a title, content and anchor link was successfully demonstrated.

**CONCLUSION**

Thus, a basic WordPress blog structure and HTML tags were successfully demonstrated.
